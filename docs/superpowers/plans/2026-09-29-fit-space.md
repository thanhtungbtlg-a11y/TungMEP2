# FitSpace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Revit 2024 `FitSpace` command that normalizes one or more existing two-elbow Pipe clusters to the spacing used by `E90to45` without replacing elements or moving the outside networks.

**Architecture:** Separate the DN/angle spacing formula from Revit so its invariants are console-tested. Revit analysis resolves an immutable five-element cluster and target translations/curves without changing the document; execution temporarily disconnects only the four local connections, translates the two existing elbows, updates three existing Pipe curves, reconnects, verifies, and rolls back only the failed cluster inside one assimilated Undo group.

**Tech Stack:** C# 12, .NET Framework 4.8, Autodesk Revit 2024 API, Nice3point secured command base, PowerShell source/reflection tests, .NET 8 console test harness.

**Spec:** `docs/superpowers/specs/2026-09-29-fit-space-design.md`

## Global Constraints

- Target Revit 2024 and `net48`; do not introduce another runtime dependency.
- Support exactly `outer Pipe – two-port elbow – middle Pipe – two-port elbow – outer Pipe`; no Tee/Wye/Cross/reducer/coupling/accessory/equipment/fixture or longer chain in v1.
- Preserve ElementId/UniqueId, type, DN, piping system, fitting orientation, two outside far endpoints, and every connection after a successful run.
- Never call the destructive `E45to90`/`E90to45` round trip, `Document.Delete`, `NewElbowFitting`, `CreateElbow`, or create replacement Pipe/fitting from FitSpace.
- Use `RawMiddleLength = 2.2 × max(ElbowData[DN])`, matching `E90to45`, and `Standoff = RawMiddleLength / (2 × sin(θ/2))`, with `15° ≤ θ ≤ 165°`.
- Reject rather than rotate an elbow, move an outside network, create an offset, or produce a Pipe shorter than `max(2 × ShortCurveTolerance, 5 mm)`.
- One command run produces one Undo item `TungMEP2 - FitSpace`; a failed cluster restores all four local connections and does not undo independent successful clusters.
- Create a timestamped restorable backup before product-source edits, including source, build/package DLL, ZIP, installed add-in manifest, hashes, and `RESTORE.txt`.
- This workspace has no `.git`; replace task commits with named backup checkpoints unless execution is moved to a Git clone.

## Review Focus

- A selected outer Pipe or ambiguous elbow must not be mistaken for a middle Pipe; Task 2 tests seed resolution from middle Pipe/one elbow/two elbows and ambiguity rejection.
- Identical selections must merge once while partially overlapping clusters must be rejected before mutation; Task 2 tests signatures and ownership overlap.
- Deleted/replaced elements or changed connector owners between analysis and execution must fail revalidation before the first disconnect; Task 3 source/reflection contracts cover UniqueId and connector-key re-resolution.
- A target requiring elbow rotation, exceeding an outside Pipe, or shortening any Pipe below the minimum must leave the cluster untouched; Tasks 2 and 3 test the analysis rejection and transaction rollback paths.
- Any failed reconnect, verification, or transaction commit must restore the original four connections and leave no transaction open; Task 3 tests the all-or-nothing cluster flow and forbids delete/create APIs.
