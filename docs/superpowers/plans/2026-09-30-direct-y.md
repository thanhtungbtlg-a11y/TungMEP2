> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe open-end DirectY connection to TungMEP2 PLUMBING.

**Architecture:** A Revit-independent geometry solver calculates rotation and local endpoint changes. A bounded Revit runner discovers exactly Pipe–elbow–Pipe and fixed Y topology, applies changes in one transaction, then validates direct connection and unchanged external ends before commit. A thin command and ribbon entry expose it.

**Tech Stack:** C# 12, .NET Framework 4.8, Revit 2024 API.

**Spec:** `docs/superpowers/specs/2026-09-30-direct-y-design.md`

## Global Constraints

- Never move the entire connected MEP component.
- Never delete an elbow in the open-end path.
- Roll back all edits if geometry or connectivity cannot be validated.
- Preserve prior TungMEP2 package in `backups/DirectY-before-20260930`.

## Review Focus

- A Y with multiple open ports must be rejected as ambiguous.
- A source Pipe with two open ends must be rejected or handled explicitly, never guessed.
- A fitting with a fourth connector must not be treated as a Y.
- A diameter mismatch must fail before mutation.
- Revit auto-propagation beyond the local Pipes must trigger rollback.
